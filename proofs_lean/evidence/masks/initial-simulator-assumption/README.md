# 撤回した既存シミュレータの前提

既存Rustシミュレータは、長語マスクが全ゼロなら下位長語の書き込みも抑止するとしていた。
最初のLean部分モデルはこの挙動を`referenceBinary`と誤って名付けて取り込んだ。
公式比較では768観測中12件が不一致となり、下位長語が常に書き込まれることを確認した。
マニュアルの「LSB側1長語には干渉しない」という読み方は全件で一致した。

ここに当時のモデル・実験コード・入力・結果・既存Rustソースを凍結保存する。
これらは現在のビルド対象でも、実際の命令を証明した資料でもない。
`referenceBinary`という当時のラベルと、既存ソースの「measured」コメントは根拠として撤回する。

現在の`Masks.lean`とRustシミュレータは、長語マスクでは下位長語を常に書き込む。
有限比較の成功を全入力・全ISAの対応証明とは扱わない。
