# 保存した不一致（解決済みとは扱わない）

最初の部分モデルは、マニュアル§3.6.12の一般則をmsl/msrにも適用し、
下位長語が各PEの第1入力から素通りすると予想した。
公式ツールとの384 PE観測のうち、循環転送の128観測で下位長語がゼロになり、不一致だった。
上位長語の転送先とフラグは一致した。

ここには当時のモデル・実験コード・入力・レポートを保存した。
Leanファイルは履歴資料であり、現在のビルド対象でも、命令の正しさを保証する証明でもない。
`sha256.json`とレポート内のソースハッシュを監査する。

現在のモデルは`manualReading`と`referenceBinary`を区別する。
後者の有限比較は384観測で一致したが、これはマニュアルと公式バイナリの対応証明ではない。
ターゲットを指定しない循環転送の意味は`unknown`のままとした。
既存の`docs/dataflow-viz/NUMERICS.md`にも同じエミュレータ挙動の記録がある。
