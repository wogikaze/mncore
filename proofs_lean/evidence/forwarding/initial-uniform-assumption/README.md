# 一律の無効化・エラー伝播という前提の撤回

最初のモデルは、対応ユニットがない通常ステップで4種類すべてのフォワーディングが無効になるとした。
また無効データからのマスクレジスタ書き込みも実行時エラーになるとした。
39ケースの公式比較は31一致・8不一致となった。

- ALUの無効データからマスクレジスタへ書いても、データのエラーは強制されず正常終了した。
- 行列転置読み出しのフォワーディングは通常ALUステップ後にも読めた。
- L1BMフォワーディングの5ケースはアセンブラの型推論で拒否され、実行時の値は分からなかった。

ここに当時のモデル・コード・39命令列・結果・ローカルシミュレータを保存する。
これらは現在の実行意味論や最適性証明ではない。
現在の既定モデルは、行列読み出し/L1BMの生成なしケースを`unknown`として扱う。
公式ターゲットの行列読み出し生成なしでのゼロ出力は明示的な別プロファイルとし、マニュアルとの一般的対応は未解決。
アセンブラの拒否を実行時エラーや不正解の証明に流用しない。
