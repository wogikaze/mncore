# 撤回した最適性主張の原文保存

このディレクトリのLeanファイルはビルド対象でも最適性証明でもない。
元の63ファイルは `sha256.json` で照合できる。
数値の検算として成立する定理と、コメントに書かれたMN-Core上の最適性主張を区別すること。

主な問題:

- 手で与えた必要行数を足して、参照行数と等しいことだけを確認していた。
- `lines < k → lines < lower` は `lower = k` なら同語反復であり、
  正しいプログラムの不存在を表していなかった。
- 既存解のnop削除や同行化の失敗から、全命令列の不可能性へ飛躍していた。
- `.optimalProven` は証拠を必要としない列挙値で、件数も独立の数値定義だった。
- 命令の実行意味論、合法性、正しい出力、入力域、初期状態との接続が存在しなかった。

元のループ設定も監査記録として保存している。再開の指示ではない。
