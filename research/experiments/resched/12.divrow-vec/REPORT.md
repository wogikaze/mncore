# 12.divrow-vec: 29 語から 28 語へ

## 結果
`best.vsm`（`gen_p1.py` が生成、`p1.vsm` と同じ）は 28 語（j=28, m=0）。公式 judge は `ACCEPTED!! score=28 j=28 m=0 bytes=1436` を返した。数値は記録済み解とビット単位で一致するので、golfcheck も OK を返す。

## 記録済み解（29 語）の仕組み
検査されるのは L1B0・MAB0 の LM1 だけである。各 PE の LM1 に 256 語を書けばよい。PE ごとの行 r は、A が lm[4r..4r+3]、B が lm[256+r] にある。

| 行 | 内容 |
|---|---|
| 1–3 | `imm 2` と `llsl $mabid` で T = 4k にする。nop は T の書き込み待ち |
| 4 | `frsqrt $mt256v`：MAB k が行 4k..4k+3 を1サイクル1行ずつ処理する。MAU は b を r0v にコピーする |
| 5 | r²。同じ行の imm 2.0 を次の行で `$aluf` として使う |
| 6–9 | Newton 法を2回。2回目の 2.0 は l1bmd 折り返しの `$lbf` から読む。行 9 で lmb = 16k を設定する |
| 10–11 | s の奇数番地にも書いて (a,a) を作る（dup）。行 11 は待ち |
| 12–15 | MAB0 が自分の行を MAU で書く。MAB1 の dup を L1BM で受け取って行 4..7 も書く（8 語/行） |
| 16–29 | MAB2..15 の積を `l1bmm@k` と折り返しで MAB0 の LM1 に流す（16 語/行 × 14） |

LM1 への書き込みは1行1命令までで、MAU は 8 語/行、L1BM は 16 語/行である。行数は「最初の LM1 書き込みまでの行数」と「256 語を流す行数」で決まる。

## 28 語にした変更
T を `ipassa $mabid $t` で T = k とし、imm を1つ減らした。MAB k が行 k+16C（C = 0..3）を担当する。

- B は `$mt256v16` で読む。
- A は lmb = 4k（`imm 2` と `llsl` を ALU の空き行 7–8 に移した）と flat 番地 `$lm[0,2,64,66]` / `$lm[128,130,192,194]` で読む。
- 受け取りは `$lln[4k,4k+64,4k+128,4k+192]` の flat 2長語書き込みにした。

鎖全体が1行前に詰まり、`zero $lmb` も要らなくなった。

## 失敗した案
- **案 A（a2 は行 9 のまま、流し込みを行 14 から始める）**
  - 4 行/MAB 方式：各 MAB のブロックは行 11 でそろう。ただし MAB0 が行 9〜13 に書けるのは 28 語で、4 語（1 行）足りない。ブロックは4行単位でしか送れない。
  - 8 行/MAB 方式：B を長語で読む（T が奇数のときの切り捨ては実測した）。偶数行の dup、奇数行の dup、送信用の積に、それぞれ別の書き込み先ファイルが要る。同じファイルへの書き込みは1行1命令までで、GRF は r と s の2つしかない。T、LM0、LM1 はどれも衝突する。
  - MAU の 2長語宛先は下位の長語を 0 にする。単語の読み出しは常に (w,0) になる。どちらも実測した。
- **案 B（鎖を短くする）**
  - rsqrt 系は MAU 命令が 5 つ要る。
  - magic 数の初期値（`isub M,b`）なら MAU 命令は 4 つで済み、この testcase の誤差は 4.6e-5 で許容内に収まる。ただし行 4 の fma に 2.0 が要り、ALU の枠（T、M、初期値）が足りない。
  - 行 4 を定数なしの t = b·p にすると、残り 3 命令では −t³+4t²−6t+4 の係数を作れない。手で場合分けして確かめた。
  - 定数不要の初期値（`$msb1−b`、`inot`）は 4 倍スケールになり、補正に定数が足りない。
  - e 拡張を使う案：`$alufe` は (half(M_hi), half(M_lo)) になり、下位レーンにしか 2.0 を作れない。LM0 を長語で読むと、下位レーンには奇数行しか来ない。
  - BAR は書き込み後に2行の待ちが要る（T は1行）。

## まとめ
T = mabid と行の割り当てを変えて 1 語縮め、28 語にした。27 語にするには、逆数の鎖をもう1行縮めるか、dup に使う書き込み先ファイルをもう1つ用意する必要がある。どちらも、ALU の枠と、同じファイルへの書き込みは1行1命令という制約に阻まれた。
