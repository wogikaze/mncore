# 13.exp-low-prec（Exp low prec）短縮の記録

結論：10語（記録済み answer.vsm）から8語に縮めた（`exp8.vsm`、`ACCEPTED!! score=8 j=8 m=0 bytes=416`）。
9語版はすでに `docs/mnist-golf/submissions/13.exp-low-prec.vsm` にあった。
7語は、使える定数の数と最初の積和に定数を2個そろえる時刻の両方で行き止まりになると判断した（§4）。

精度（許容誤差は絶対誤差 0.009）：
- テストケース：0.007902
- [-2,2] の密な格子 409,600 点（公式エミュレータ）：0.008130（x=1.99512）
- |x| ≤ 2 のすべての float32（`model.py`、エミュレータとビット一致を確認済み）：0.008130

```
imm ui"0x3C25397C" $llr16/ll1000
imm ui"0x3D5954A4" $nowrite; l1bmrffadd $aluf $llbi
hpassa $llm0vr $lt; hvfma $llr16r $llm0vr $aluf $nowrite; l1bmm $llbi $nowrite
imm ui"0x3EF4233E" $nowrite; hvfma $maufr $aluf $lbf $nowrite
imm ui"0x3F80AC80" $nowrite; hvfma $maufr $lt $aluf $nowrite
imm ui"0x3F80F7A9" $llr24/ll1000; hvfma $maufr $lt $aluf $lls0v
fvfma $mauf $lm0v4 $aluf $ln0v4
fvfma $ls2v4 $lm2v4 $llr24 $ln2v4
```

## 1. 問題と記録済みの解

- 入力は x ∈ [−2, 2] の4096要素で、全 MAB に同じものが置かれる。出力は各 L1B の m0 の LM1（PE あたり16語）。
- 許容誤差は絶対誤差 0.009 と大きい。期待値と exp(float32 x) の差は 8.5e-7 で、無視できる。
- 半精度の MAU 命令（hv*）は1命令で16語すべてを処理する。A・B 入力は半精度（s1e6m9、`r` を付けると f32 を丸めて入力）で、C 入力と結果は f32 である。単精度の fv* は1命令8語なので、全要素に2行かかる。
- answer.vsm（10語、syttrea）は e^x = (e^{x/2})² で計算している。
  - `hlrelud $msb1` で T = x/2（半精度）を作る。
  - 半精度 Horner を4段回す。係数のうち 0.168 は、0.042 を `l1bmr4ffadd` で4倍して作っている。
  - 最後の段 E = D·y + 1 と2乗 E² は単精度で、それぞれ2行ずつかかる。
- 9語版（docs/mnist-golf）は2乗をやめ、Y = c0 + x·S4(t) の5次を直接計算する。
  - S4 は半精度 Horner 4段で作る。
  - 最後の積だけは厳密な f32 の x を使い、fvfma 2行で計算する。
  - 定数は imm 6個（c0 は aluf と GRF0 に兼用）。
  - 密な格子での最大誤差は 0.0086。

## 2. 8語版 exp8.vsm のしくみ

Y = C0 + x·S4。各段は次のとおり。

- S1 = h(A4)·h(x) + A3
- S2 = h(S1)·h(x) + 16·A4
- S3 = h(S2)·h(x) + A1
- S4 = h(S3)·h(x) + A0

x の5次式としての係数は (C0, A0, A1, 16A4, A3, A4) になる。

1. **係数の縛り（tie）を2つ入れて、自由な定数を4〜5個に減らした。**
   - 次数5の minimax 誤差は 0.00326。2のべき比の縛りを全通り LP で調べると、次の2つは誤差がほとんど増えない。
     - a3 = 16·a5：誤差 0.00336
     - a0 = a1：誤差 0.00336
   - 両方を同時にかけても 0.00339 で済む。
   - 16倍は `l1bmrffadd $aluf`（16 MAB 縮約）で作る。全 MAB が同じ imm を持つので、和はちょうど16·A4 になる。
   - 縛りを3つにすると、最良でも近似だけで 0.0102 になり、許容誤差を超える。
2. **縛りを生かす時刻の割り当て。**
   - L1：A4 を imm で GRF0 に置く。
   - L2：A3 の imm と同じ行で、L1BM の16倍縮約をかける。
   - L3：LM0 を読む行（imm は置けない）。
     - MAU は x を LM0 から直接読み、S1 = GRF0(A4)·x + aluf(A3) を計算する。
     - ALU は `hpassa` で T = x を作る。
     - L1BM 欄では `l1bmm` で 16A4 を放送する。
   - L4：S2 の x には、L3 の ALU 結果（`$aluf` = h(x)）をそのまま使う。定数は `$lbf`（16A4）。同じ行で A1 の imm を置く。
   - L5：S3。T を読む。同じ行で A0 の imm を置く。
   - L6：S4 を計算し、GRF1 にもコピーする。同じ行で C0 を imm で aluf と GRF0 に置く。
   - L7・L8：fvfma で Y = S4·x + C0 を偶数語と奇数語に書く。
   - L6 の ALU 欄が空いていたので、a0 = a1 の縛りは外し、C0 を独立にした。
   - 倍率の制約：16倍の縛りが成り立つには、T と aluf の倍率が1（x をそのまま使う）でなければならない。そのため `hlrelud`（x/2）ではなく `hpassa` を使った。
3. **丸めを見込んだ係数の選び直し。**
   - 生の LP 係数のままの `c8.vsm` も ACCEPTED だった。ただし密な格子での誤差は 0.0088 で、余裕がない。
   - `model.py` で半精度の丸め（RNE）と、積和1回の丸めを再現した。公式エミュレータとビット一致することを確認してある。
   - 係数は `lp2.py`（丸め残差を固定して LP を反復）と `opt2.py`（float32 格子上のランダム局所探索）で選び直した。
   - 対象は、テストケースの点と 40 万点の密な格子の両方の最大誤差。
   - 採用した係数（f32）：

     | 係数 | 値 |
     |---|---|
     | A4 | 0.010084506 |
     | A3 | 0.053059235 |
     | A1 | 0.47683138 |
     | A0 | 1.0052643 |
     | C0 | 1.0075580 |

   - 誤差の大部分は、x≈2 付近で半精度に丸める誤差（入力 x と途中の S の両方）である。x≈0 では C0 の偏り 0.0076 が出るが、許容内。

## 3. 試したこと

- 半精度だけで最後の積まで計算する（1行で済む）案：最後の積の入力を半精度に丸める誤差だけで、最大およそ 2·2^-10·|積| ≈ 0.01 になる。C に厳密な f32 の x を入れても 0.0105 程度で、使えない（9語探索の記録でも 0.0107）。
- x − h(x) で補正する案（e^x ≈ E·(1+r)）：E 自体の最後の積が半精度になるので、同じ理由で駄目。
- 4次まで落とす案：minimax 誤差 0.0202 で不足。
- 最初の段で定数を1つしか使わない形：
  - k·x + {0, x, k} と x² + k を考えた。いずれも a4 が 0 になるか、a4/a5 が2のべきに縛られる。
  - 必要な比はおよそ5で、2のべきに縛ると近似だけで 0.0076 以上になる。
- 定数を使わない段の多項式（x²、x²+x など）で上位の係数を固定する案：a4・a5 を固定したまま許容に収めるには、両方の値が 2% 以内で合っていなければならない。2のべきの組み合わせではそこまで合わない。
- 固定値オペランド（`$msb1`、`$mabid` など）から ALU 1命令で浮動小数点の定数を作る案：0x7FFFFFFF などしか作れず、役に立たない。
- MAB で偶数語と奇数語を分けて最後の f32 を1行にする案：L1BM での転送に2行かかり、かえって長くなる（14.exp と同じ理由）。

## 4. 7語が無理な理由（下限）

- **最後の f32 2行は省けない。** 半精度の最後の積では誤差が足りなくなる（§3）。最後の2行は LM0 を読むので imm を置けない。
- **定数の数が足りない。**
  - 残りは L1〜L5 の5行で、そのうち少なくとも1行は x を読むために LM0 を読む。そのため imm は最大4個。
  - 2のべきの縛りを3つ入れる族では、近似だけで 0.0102 になる。よって自由な定数が4個必要で、余りはない。
- **定数を2個そろえる時刻が間に合わない。**
  - S4 を L5 までに出すには、S1 を L2 に置くことになる。
  - S1 = A4·x + A3 には定数が2個要る。L2 で使えるのは L1 の imm からの aluf だけで、GRF0（2行前の書き込みが必要）も lbf（3行前の imm が必要）も間に合わない。
  - 最初の段の定数を1個にすると、a4/a5 が 0 や2のべきに縛られるか、上位の係数が固定値になる。どの場合も誤差が許容を超える（§3）。
- 定数の出どころは imm しかない。メモリはすべて 0 で初期化され、LM0 には x しかない。
- 以上から、この命令セットでは8語が下限と判断した。
