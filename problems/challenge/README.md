# MN-Core Challenge（通常問題）

出典: https://mncore-challenge.preferred.jp/problems/

順位表で各問題の最小行数の提出を選びます。練習問題の公式想定解も `official.vsm` に保存します。
サイト上の Accepted を確認して保存しています。ローカルでの検証結果は各 `answer.json` の `local_validation` を参照してください。
