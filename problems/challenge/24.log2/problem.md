# Log 2

- Top: 7 lines / syttrea
- Par: 35 lines

## Problem Statement

\(2\) のべき乗の `Int` \(X[i]\) が与えられます。
\(Y[i] = \log_2(X[i])\) を求めてください。

## Additional Constraints

* 各 \(X[i]\) は \(2\) のべき乗である

## Inputs

* \(X\) (\(1 \le X[{i}] \le 2048\)): Int `$lm[0:32]`, `/((16_MAB:1, 4_PE:1, 16:1, 2_W:1); B@[L1B,L2B])`

## Outputs

* \(Y\): Int `$ln[0:32]`, `/((16_MAB:1, 4_PE:1, 16:1, 2_W:1))`
