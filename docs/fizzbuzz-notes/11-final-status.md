## 検証済みの技法（未統合）
- **FMA mod 15**: base 0x452A0000, K=0x4488A854 で `(F>>32)&15 == n%15`（n≤6334, 全数検証）。
- **iand 120 mod 3/5**: n を float とし `iand(fvmul(n,1/3),120)==0` ⟺ 3の倍数。
- **iand 120 のマスクフラグ**: 「出力が全0」で1（SDM 3.6.12.1）。

## 93行の構造（解読済み）
- 座標 b = (l2bid,l1bid,peid)、m=8b。
- 位置 s0 を {0,32,408,4672} と比較して桁域選択。
- b（ブロック先頭数値, float）と c（位相, fftoi, lr18）を計算。
- T 連鎖: `w*k + {8,13,23,33,33}` を lsub マスクで選択（11 ALU）。
- v1/v2 を `$mt[43,41]` から取得し、数字を描画後、Fizz/Buzz 文字で上書き。
- pack: 6 ALU で8バイトを構築。転送: l1bmd→l2bmd→mvd→mvp（2 MV）。

### 新たに否定した経路
- **位相 (p mod 79) の FMA 化**: `iand` 系トリックは倍数判定（全0）のみで剰余は得られない。
  アフィン写像で `X mod 79` を厳密に得るには 79|2^k が必要で不可能。
  私の mod 15 定数（0x4488A854）は剰余を与えるが、79 では同様の定数が存在しない（探索済み）。
- **テンプレート一括放送**: 79バイト周期は語境界に整列せず、8周期=632バイト=79語のスーパー周期でも数字が毎周期変化するため固定放送不可（fb52 も 14/79 語のみ固定と確認）。
