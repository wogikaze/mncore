# L2B

[[Level-2 Broadcast Block]](L2B)には、8個の[[L1B]]と1個の[[L2 Broadcast Memory]]([[L2BM]]) があります。
[[L1BM]]と[[PE]]/[[MAB]]の間と同様に、L2BMとL1Bは、L2BMからL1Bへの放送(データ転送)、L1BからL2BMへの[[個別・縮約データ転送]]などの多様なデータ転 送を行うことができます。
 これらのデータ転送も、[[PE命令]]によって制御されます。
  最後に、L2Bは、[[ホストインターフェース]]及び外付け[[DRAM]]と、多様な方法でデータ転送を 行うことができます。
