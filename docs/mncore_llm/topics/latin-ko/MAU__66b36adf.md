# MAU

[[Matrix Arithmetic Unit]](MAU)はPEから入力データを受け取り演算処理を行い出力データをPEに戻します。
MAUは[[行列演算]]に用いる専用の[[行列レジスタ]]を持っており、これは[[行列ベクトル積]]で使う行列を保持します。
行列レジスタは2面存在しているため、[[行列レジスタ1]]に書き込みながら、[[行列レジスタ2]]を用いて行列演算を行うことが可能です。

[[MAUで可能な演算]]
 ● [[積和演算]]
  ○ [[ベクトル積和演算]] (A x B + C) :半精度、単精度、倍精度
   [[vfma]]
  ○ [[行列積和演算]] (A x 行列レジスタ + C) :半精度、疑似単精度、単精度、倍精度
   [[mfma]]
 ● [[行列レジスタ書き込み]] :半精度、疑似単精度、単精度、倍精度 
  [[mwrite]]
 ● [[行列レジスタ転置読み出し]] :半精度、疑似単精度、単精度、倍精度
  [[mread]]
