# L1B

[[Level-1 Bloadcast Block]] (L1B)には、16個の[[MAB]]と1個の[[L1 Broadcast Memory]]([[L1BM]]) があります。
 L1BMとMABは、L1BMからMAB ([[PE]]) への[[放送データ転送]]、[[個別・縮約データ転送]]、[[分配(結合)データ転送]]などの多様なデータ転送を行うことがで きます。
  これらのデータ転送は、PEと同様に[[PE命令]]によって制御されます。
  これらの転送モードにより、[[階層キャッシュ]]による[[マルチプロセッサ]]では困難な、[[細粒度並列タスク]]の高 い効率での実行を可能にしています。
