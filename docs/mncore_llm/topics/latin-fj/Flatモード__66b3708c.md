# Flatモード

[[Flatモード]]では、[[命令ストリーム]]の 1 単位は 2 つの[[PE命令]]と 1 つの[[MV命令]]から構成される。
[[Flatモード]]は[[ステップ]]あたりの[[命令帯域]]が大きくなる代わりに[[アドレス指定]]を柔軟にしたものである。
 具体的には、[[ステップ]]内の各[[サイクル]]で、[[GRF0]]、[[GRF1]]、[[LM0]]、[[LM1]]の[[アドレス値]]をすべて指定する。
 それ以外の[[メモリ]]の[[アドレス]]は[[Auto strideモード]]同様、自動的に決まる増分値を第 0 [[サイクル]]の[[アドレス]]に加えることで決定される。
 さらに[[PE命令]] 2 つと[[MV命令]] 1 つを合わせたものが[[命令ストリーム]]の 1 単位となり、これが繰り返される。
