# 3.5 MV命令文

本節では[[MV命令]]の文法と効果を述べる。
[[データ移動]](MV)命令文は4ステップに1回実行されるMV命令に翻訳される単位である。
MV命令文には[[PE命令文]]と異なり、式をセミコロンで区切る形式はなく、改行で終端する単一の文のみが許される。
