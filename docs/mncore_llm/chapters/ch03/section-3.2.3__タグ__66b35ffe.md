# 3.2.3 タグ

タグは[[MV命令]]と[[PE命令]]の間の[[待ち合わせ]]のための値である。
タグは識別のため必ず先頭に`i`を付け、その後 [[0埋め]]ありで 2 桁固定の 16 進数でタグ値を記述する。 
 範囲は`[[0,63]]`(つまり`i3f`まで)
16 進数であるがプレフィックス`0x`は付かない。
実例は[[wait命令式]]の節([[3.6.13 wait-PE命令にMV命令を待機させる]])に譲る。
