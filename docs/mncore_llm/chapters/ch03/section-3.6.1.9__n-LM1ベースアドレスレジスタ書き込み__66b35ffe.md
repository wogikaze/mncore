# 3.6.1.9 n-LM1(ベースアドレスレジスタ書き込み)

[[LM1]]の[[ベースアドレスレジスタ]]([[BAR]])への書き込みを行うための[[オペランド]]の文法は次の通りである。

```txt
$[l]nb

```
ここでは[[マスク適用]]([[3.6.2.1 書き込みマスク適用]])については省略する。括弧で付した節を参照のこと。
効果については[[LM0]]のもの([[3.6.1.7 m-LM0(ベースアドレスレジスタ書き込み)]])と同様である。
