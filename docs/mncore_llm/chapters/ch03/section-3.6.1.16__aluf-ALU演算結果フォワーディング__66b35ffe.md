# 3.6.1.16 aluf-ALU演算結果フォワーディング

次の[[オペランド]]からは[[nop]]と[[noforward]]を除いた直前の[[ステップ]]で[[ALU]]が出力したデータを読み出せる。
データ生成元以外の性質は[[MAU演算結果フォワーディング]]([[3.6.1.15 mauf-MAU演算結果フォワーディング]])と同じである。

```txt
$aluf

```
```例
dbfn $lr0v $lr0v
dmwrite $aluf $lx0

```
[[倍精度BF化]]の結果を[[GRF0]]に書き込み、次の[[ステップ]]でそれを[[行列レジスタ]]に書き込む。
