# 3.6.9.21 hvpassa -半精度ベクトルコピー演算

[[hvpassa]]は基本動作 [[hvfma]]の第 2 入力を 1、第 3 入力を 0 としたもの、すなわちコピーを行う命令である。
[[積和演算]]は行われないが、浮動小数点数としての[[正規化]]が行われるため、完全なコピーとはならないことに注意する。
