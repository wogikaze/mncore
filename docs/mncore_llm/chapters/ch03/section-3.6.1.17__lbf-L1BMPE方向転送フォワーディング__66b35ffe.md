# 3.6.1.17 lbf-L1BM→PE方向転送フォワーディング

次の[[オペランド]]からは[[nop]]と[[noforward]]を除いた直前の[[ステップ]]で[[L1BM]]からPEに転送されたデータを読み出せる。
データ生成元以外の性質は[[MAU演算結果フォワーディング]]([[3.6.1.15 mauf-MAU演算結果フォワーディング]])と同じである。

```txt
$lbf

```
```例
l1bmm $lb0 $lr0v
dvadd $lbf $lbf $ls0v

```
[[L1BM]]から[[GRF0]]に[[MAB放送]]を行い、次の[[ステップ]]でその 2 倍を計算して[[GRF1]]に書き込む。
