# MN-Core 2 データ移動ビジュアライザ 再設計

## 目的

「どの命令が、ハードウェアのどこで、どんなデータ移動・演算を起こし、値がどう変わったか」を、
1画面で読み取れるようにする。装飾ではなく、情報の優先順位と視線の流れで理解を助ける。

## 情報の優先順位

1. **現在の命令・ステップ・サイクル** — 画面上部の Now バーに常時表示する。
2. **現在動いているハードウェアとデータフロー** — 中央メインのデータフロー図を最大面積で使う。
3. **値の読み出し元・書き込み先・変化** — データフロー図の左右に before / after / delta を併記する。
4. **チップ全体での現在位置** — 中央上部のコンパクトな Overview で、Group / L2B / L1B と選択箇所を示す。
5. **その他の状態** — 右の詳細パネル（来歴・競合・メモリ・占有）に退避する。

## 画面構成（1440×900 の基準）

```
┌─────────────────────────────────────────────────────────────────────┐
│ Top bar: brand / Explorer–Story / problem / panel toggles / theme    │ 44
├─────────────────────────────────────────────────────────────────────┤
│ Now: 行番号 + 命令 + step/cycle + score + 現在のハードウェア + 状態   │ 52
├──────────────┬──────────────────────────────────────┬───────────────┤
│ VSM source   │ Overview map (compact, clickable)    │ Detail panel  │
│ 現在行、NOP  │ Group ×4 / L2B / L1B / 現在位置       │ 値 / 競合     │
│ 診断、競合   ├──────────────────────────────────────┤ メモリ / 占有 │
│              │ Dataflow detail (largest area)       │               │
│              │ breadcrumb + source → unit → dest    │               │
│              │ before/after/delta + step diff       │               │
├──────────────┴──────────────────────────────────────┴───────────────┤
│ Transport: play / step / cycle / timeline / speed / score            │
└─────────────────────────────────────────────────────────────────────┘
```

- 左右ペイン、Overview の高さ、下部タイムラインの高さはドラッグで変更できる。
- 各ペインは折りたたみできる。折りたたみ時は Top bar のトグルで復帰する。
- 中央の Dataflow が最も広い面積を常に確保する。

## 階層と探索

- 階層: `Chip → Group → L2B → L1B → MAB → PE`。
- Overview は位置把握のための簡略図。Group の活動、選択中の L1B、現在の記録 MAB を示す。
- 詳細はスコープをもつ:
  - `全体`: チップ全体の Overview を拡大し、転送の流れを見る。
  - `Group`: 2 L2B × 8 L1B の活動と Group 内の流れ。
  - `L1B`: 16 MAB、共有 L1BM、現在行の L1BM↔PE の流れ。
  - `MAB`: 4 PE の読み出し→演算→書き込みを並べる。
  - `PE`: 1 PE のデータフロー（既存 Datapath を拡張）。
- パンくずリストで現在の階層を明示し、各要素をクリックして戻れる。
- 「現在位置に追従」を既定で ON。命令が変わると、その命令が動かすスコープへ自動で切り替える。
- ユーザーが Overview やパンくずから箇所を選ぶと追従を OFF にし、選択を勝手に変えない。
  「追従」ボタンで再開できる。
- Group / L1B / MAB / PE を選ぶと、その MAB を記録し直して値が取れる状態にする。

## データフロー図

- 左に読み出し元、中央に演算器、右に書き込み先を置く。
- 読み出し元には「値」、書き込み先には「更新前 → 更新後（差分）」を表示する。
- 経路は常に描き、現在行で使われる経路を色と太さで強調する。使われない経路は細く暗くする。
- 矢印は方向を明示する。演算器には opcode と入力名（x / y / a / b / c）を表示する。
- 4 サイクルのうち、現在のサイクルを強調する。サイクル選択は図とタイムラインで共有する。
- 現在行の変更を「前の行からの差分」として図の下に列挙する。
- アニメーションは再生時だけ、経路に沿った控えめなパルスとして使う。

## 視覚デザイン

- ダークテーマを既定にする。ライトテーマは Top bar のトグルで切り替え、設定を保存する。
- 色は意味だけに使う:
  - ハードウェア: Layer Block = 青、Memory = 黄、Processing = 灰、DRAM/PDM = 紫。
  - データ: DRAM/PDM = 紫、L2BM = 青、L1BM = teal、PE 演算 = 橙、MAU = 桃。
- 状態:
  - Active = 色付きの面 + 明るい枠
  - Selected = 白い太枠 + パンくずと同期
  - Updated = 橙の小さなマーカー / 差分表示
  - Inactive = 低コントラスト（文字は読める範囲）
- 本文 13px、データ 12px、ラベル 11px を下限にする。8px の文字は使わない。
- 値やアドレスは等幅。桁揃えと右寄せで比較しやすくする。
- 主要情報は常時表示し、ツールチップは補助に限定する。
- 空白は「情報のまとまり」に使う。ペイン内の余白を詰め、Dataflow に面積を渡す。

## 操作性

- VSM 行クリック、Overview クリック、データフロー内の値クリック、タイムラインのスクラブを連動させる。
- 行を選ぶと Now バー、データフロー、Overview の強調、詳細パネルがすべて同じ行に追従する。
- 値の来歴は既存の `provenance` を使い、入力クリックで根まで辿れるようにする。
- 前後の行・サイクル移動、再生、速度、シークは下部に集約する。
- 既存のキーボード操作（←→、Shift+←→、Space）を維持する。

## 維持する機能

- Explorer / Story モード。
- 問題選択、VSM 編集、VSM / testcase のドラッグ＆ドロップ。
- VSM ソースの行番号、現在行、NOP の必要理由・削れる候補、競合リンク。
- チップ Overview、Group / L2B / L1B / MAB / PE の階層。
- PE データパス（読み出し元・演算器・書き込み先、4 サイクル、値の表示形式）。
- PE メモリ（LM0/LM1/GRF0/GRF1/T/OMR、ページ、現在行の書込み、来歴選択）。
- 命令グループ占有と資源下限。
- Inspector（出力判定、行の詳細、競合、値の来歴）。
- タイムライン（再生、行/サイクル移動、速度、シーク、カテゴリ別の量）。
- Story のスクロール連動。

## 実装状況（2026-10-19）

- Now バー、VSM ソース、チップ概要、スコープ別データフロー、右詳細、下部トランスポートを実装した。
- スコープは `全体 / Group / L1B / MAB / PE`。全体は Group 別の転送サマリ、Group は L2B×L1B、L1B は 16 MAB と L1BM、MAB は 4 PE の読み出し→演算→書き込み、PE は既存 Datapath を拡張した。
- 値を選ぶと右パネルの来歴に連動する。L1BM 読み出しは L1B の書き込みまで正規化して辿る。
- 現在行の書き込み差分を StepDiff に、右パネルにも before → after を表示する。
- ダークテーマを既定にし、ライトテーマを切り替えられる。レイアウトは localStorage に保存する。
- 既存のメモリ表示、占有表示、NOP 診断、競合、Story、キーボード操作は維持した。
- 1440×900 で主要ペインの overflow がないこと、メモリ/占有/Story/ライトテーマ/折りたたみ/リサイズをブラウザで確認した。
